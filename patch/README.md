# Patch assets (public mirror)

This folder is reserved for **small in-app update ZIPs** (`dlss5_patch.json` + `assets/`), published via admin releases on Vercel.

Upload new patch bundles here when you want a GitHub mirror URL for `download_url`.

**Do not** put full installers here — use [GitHub Releases](https://github.com/superdlls/superdlls5/releases) for `Super_DLLS5_Setup_*.exe`.
